
# ERL-HUB
## Emergency Relief Logistics & Unified Backend

A C++ based disaster relief logistics management system designed to manage relief inventory, emergency missions, vehicles and priority-based dispatch operations.

## Features

- Inventory management using OOP
- Dynamic memory management and deep copying
- Operator overloading
- Inheritance and polymorphism
- Multiple and virtual inheritance
- Abstract classes and virtual destructors
- STL containers and algorithms
- Template-based priority dispatch queue
- Functors and operator overloading
- File handling using binary files
- Persistent inventory and mission storage
- Custom exception handling
- Integrated mission and vehicle dispatch system

## Tech Stack

- C++
- STL
- Object-Oriented Programming
- Binary File Handling

## Project Structure

```text
ERL-HUB/
├── include/
├── src/

├── docs/

```

## Build and Run

Compile using:

```bash
g++ -std=c++17 -Iinclude src/*.cpp -o ERL-HUB.exe
```

Run on Windows:

```powershell
.\ERL-HUB.exe
```
